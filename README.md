# BookSocial

Plataforma web de gestión de lectura y comunidad literaria (estilo Goodreads).

Proyecto para prácticar con microservicios con Java 21 + Spring Boot, Angular 21,
CQRS + Event-Driven (RabbitMQ), PostgreSQL/MongoDB, CI/CD con GitHub Actions
y despliegue con Docker/Terraform y GCP. Redis para rate limit. Google Library Api para libros y Open library para autores (cross reference).
