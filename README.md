# BookSocial

Plataforma web de gestión de lectura y comunidad literaria (estilo Goodreads).

Proyecto de portfolio: microservicios con Java 21 + Spring Boot, Angular 21,
CQRS + Event-Driven (RabbitMQ), PostgreSQL/MongoDB, CI/CD con GitHub Actions
y despliegue con Docker/Terraform.

Roadmap y decisiones: ver `docs/ROADMAP.md`.
